# 마켓별 검증 가이드

마켓별 `verified` 상태는 각 어댑터와 README 표를 참고하세요. 아래 절차로 **실제 판매자 계정**에서
확인한 뒤 `selectors`와 `verified: true`를 반영합니다. 확인 전 셀렉터를 추정으로 채우지 않습니다.

## 검증 체크리스트

각 마켓마다 아래를 수행하고 결과를 이 문서에 기록합니다.

1. **계정·권한**: 테스트 가능한 판매자 계정, 등록 권한, 브랜드/카테고리 승인 상태 확인.
2. **진입 URL**: 로그인 후 상품 등록 화면의 실제 URL(해시 라우팅 포함)을 기록.
   - `MarketplaceAdapter.urlPatterns`는 `pathname + hash`에 대해 검사합니다.
3. **폼 스캔**: 확장의 `폼 스캔`으로 입력란 라벨·`name`·`id`·`required`를 수집.
4. **필드 매칭**: `폼 채우기`(실입력) 전에 가능하면 dryRun으로 매칭 상태를 확인.
5. **셀렉터 확정**: 반복 실행에도 안정적인 것만 `selectors`에 추가.
   - `name`/`id`가 해시·랜덤이면 라벨 텍스트 매칭에 맡깁니다.
6. **특수 동작**:
   - 카테고리: 검색 모달/트리 → 수동 유지 또는 `categoryCodes` 기반 선택 단계 설계.
   - 옵션: 옵션 축 추가, 값 입력, 옵션별 가격·재고 → 커스텀 단계 필요 여부 기록.
   - 상세 에디터: iframe/`contenteditable`/에디터 API 여부, HTML 보존 가능 여부.
   - 이미지: 다중 업로드, 순서, 대표 지정, 규격(정방형/용량).
   - 배송·반품: 정책 선택인지 직접 입력인지.
7. **검증 표시**: 위 결과를 반영해 `verified: true`로 바꾸고, 검증일·계정 유형을 커밋 메시지에 남김.
8. **회귀**: `npm run verify`. 감지 테스트와 DOM 테스트에 실제 라벨/구조를 반영.

## 기록 템플릿

```md
### 스마트스토어 (YYYY-MM-DD, 판매자 유형: 개인/사업자)

- 등록 URL:
- 폼 스캔 결과: (라벨/name/id)
- 안정 셀렉터:
- 수동 항목: 카테고리, 옵션, ...
- 특이사항: 스마트에디터 iframe 여부, 이미지 규격, ...
- 검증자:
```

### 에이블리 (2026-10-21, 실제 판매자 계정)

- 등록 URL: `https://my.a-bly.com/goods/v2/register`
  - 실제 폼: `https://seller-admin.a-bly.com/goods/register?iframe=true` (교차 출처 iframe)
- 폼 스캔 결과: Ant Design 기반. `#name`, `#custom_code`, `#prices_0_consumer`, `#standard_category`,
  `#file-upload`(대표/커버 2개, 둘 다 숨김), `div.fr-element[contenteditable="true"]`.
- 안정 셀렉터:
  - 상품명 `#name`, 판매자상품코드 `#custom_code`, 판매가 `#prices_0_consumer`
  - 상세 설명 `div.fr-element[contenteditable="true"]`
  - 대표 이미지 `input[type="file"][accept*="gif"]`, 커버 이미지 `input[type="file"][multiple]`
  - 해시태그 `input[placeholder="해시태그를 입력하세요"]` (Enter로 칩 등록)
- 수동 항목: 카테고리, 브랜드, 옵션 조합/재고, 배송 정책, 상품정보제공고시.
- 특이사항: 상품 상태는 `신상품`/`중고`만 제공. 해시태그는 공백 불가·최대 30개.
  이미지 파일 input이 `display:none`이라 숨김 input도 탐색 대상에 포함한다(보이는 입력란 우선).
- 검증자: 사용자 판매자 계정 세션으로 DOM 확인 및 텍스트 필드·해시태그·상품 상태 입력 확인.

### 11번가 (2026-10-21, 비로그인 공개 등록 페이지)

- 확인 URL: `https://soffice.11st.co.kr/pages/product-reg/index.html` (실제 등록 iframe)
- 실제 입력 확인: 상품명, 브랜드, 판매가, 정가(숨김), 재고수량, 판매자 상품코드,
  원산지(국내/지역), 상품상태, 상품상세(HTML textarea), A/S안내, 반품 배송비, 과세여부.
- 함께 채우지 않음: 홍보문구, 추가상품명, 구입 당시 판매가, 최소/최대구매수량.
- 미지원/수동: 카테고리, 옵션, 배송비 정책, 배송기간(11번가의 `평일` 셀렉트가
  시간/출고일 select를 함께 사용해 자동 매칭하지 않음), 이미지.
- 비로그인 상태라 페이지 자체의 상품정보 로딩 오류 모달이 뜰 수 있음. 저장·제출은 하지 않음.
- 실제 판매자 계정 검증 전이므로 `verified: false`를 유지한다.

## 실제 로그인 계정 라이브 테스트 (2026-10-21)

로그인된 CDP Chromium 세션에서 실제 등록 폼에 `dist/content.js`를 주입해 `PREFILL`을 실행했다.
저장·제출·게시·결제 버튼은 누르지 않았다.

| 마켓 | 실제 입력 확인 | 자동 입력이 막히는 부분 |
|---|---|---|
| 스마트스토어 | 상품명, 브랜드, 제조사, 판매가, 재고, 판매자 코드, 바코드, 상품상태, 태그, 상세설명, 기본 배송비, 배송방법, A/S | 원산지(Selectize 3단), 정가, 배송기간, 반품배송비, 카테고리·이미지·옵션은 수동 |
| 쿠팡 Wing | 노출상품명(등록상품명 자동 동기화) | 카테고리를 선택해야 가격·옵션·상세·고시 섹션이 렌더링됨. 브랜드·카테고리·이미지·옵션 수동 |
| ESM Plus | 상품명, 브랜드, 판매가, 재고, 판매자 관리코드 | 브랜드/제조사가 같은 검색 input을 공유(제조사는 건너뜀), 원산지·상품상태·배송은 커스텀 버튼형이라 수동 |
| 11번가 | 상품명, 브랜드, 판매가, 정가, 재고, SKU, 원산지, 상품상태, 상세(HTML), A/S, 반품배송비, 과세여부 | 이미지 업로드 다이얼로그, 카테고리·옵션·배송정책 수동 |
| 에이블리 | 상품명, 판매가, SKU, 상세, 해시태그, 상품상태 | 카테고리·브랜드·옵션·배송정책·고시정보 수동 |

- 접힌 섹션은 어댑터 `prepare`의 `expandSections`로 자동으로 펼친다.
- 스마트스토어는 이전 작성 내용(임시저장)을 불러오라는 사이트 모달이 뜰 수 있다. 자동으로 확인하지 않는다.
- ESM Plus의 `상품 주요정보`는 브랜드/제조사가 한 input을 공유하므로 엔진이 두 번째 필드를 `manual`로 남긴다.

## 주의

- 자동화 범위는 각 마켓의 판매자 이용약관과 운영정책을 따릅니다.
- CAPTCHA·본인인증·OTP는 자동화하지 않습니다. 사용자가 직접 처리합니다.
- 계정 공유·대리 등록 도구가 아닙니다. 판매자 본인 세션에서만 동작합니다.
- 마켓 화면 개편으로 매칭률이 떨어지면 `폼 스캔` 결과를 기준으로 라벨 별칭을 갱신합니다.
