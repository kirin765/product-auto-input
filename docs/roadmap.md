# 로드맵

## 0. 스캐폴드 (완료)

- 표준 상품 모델·정규화·검증
- 공통 DOM 엔진(라벨 매칭, 네이티브 값 설정, 이미지 업로드, 폼 스캔)
- 7개 마켓 어댑터 골격과 감지
- 팝업 UI(JSON 입력, 검증, 폼 채우기, 스캔, 리포트)
- Vitest 46개, typecheck, esbuild 빌드, CI

## 1. 파일럿: 스마트스토어 + 쿠팡 (다음)

목표: 실제 판매자 계정으로 **상품 1건을 끝까지 등록**하되 제출은 수동.

- [ ] 스마트스토어 등록 화면 DOM 검증, 안정 셀렉터 반영
- [ ] 쿠팡 다단계 마법사 단계별 필드 명세 분리
- [ ] 이미지 업로드 CORS/규격 확인, 실패 시 대체 안내
- [ ] 상세 에디터(iframe/리치 텍스트) 입력 방식 확정
- [ ] 카테고리 선택 단계 설계(`categoryCodes` 활용)
- [ ] 필드별 신뢰도·수동 항목 리포트 개선
- [ ] 실제 라벨 기반 DOM 회귀 테스트 추가

## 2. 옵션·카테고리 자동화

- [ ] 마켓별 옵션 빌더 커스텀 단계(축 추가, 값, 옵션가, 재고)

- [ ] 카테고리 코드/경로 검색·선택
