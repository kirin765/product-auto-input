상품 정보를 한 번 준비하고, 판매자센터에서 반복되는 입력을 줄이세요.

상품 등록 도우미는 CSV/XLSX 고정 양식 또는 JSON으로 준비한 상품 정보를 현재 판매자센터의 상품 등록 폼에 채웁니다. 입력 결과를 확인한 뒤 저장·제출은 판매자가 직접 진행합니다.

주요 기능
• 1개 상품용 CSV/XLSX 템플릿 다운로드와 가져오기
• 누락된 값과 형식 오류 확인 및 수정
• 상품 JSON 편집, 로컬 초안 저장, JSON 내보내기
• 현재 등록 화면의 폼 스캔
• 상품명·가격·재고·SKU 등 매칭되는 입력란 채우기

사용 방법
1. 확장 팝업에서 1개 상품의 정보를 준비합니다.
2. 본인의 판매자 계정으로 로그인한 뒤 상품 등록 화면을 엽니다.
3. 마켓을 선택하고 '폼 스캔'으로 입력란을 확인합니다.
4. '폼 채우기' 실행 후 값과 수동 항목을 검토합니다.
5. 저장·등록은 직접 진행합니다.

요금
무료는 하루 5회까지 폼을 채울 수 있습니다. 구독은 월 ₩4,900이며 폼 채우기 횟수 제한 없이 사용할 수 있습니다. 결제는 Paddle이 처리하고, 제품 사이트에서 언제든 다음 결제를 해지할 수 있습니다.

지원 범위
판매자센터별 일부 필드를 지원하는 초기 버전입니다. 카테고리, 옵션, 이미지, 상세 에디터는 수동 작업이 필요할 수 있습니다. 여러 단계의 등록 화면은 단계마다 다시 실행하세요. 실험적 어댑터에는 미검증 필드가 있으며 모든 계정과 화면에서의 동작을 보장하지 않습니다. 마켓별 확인 필드와 제한은 홈페이지의 지원 범위 표를 참고하세요.

개인정보
상품 초안과 폼 입력 데이터는 브라우저 로컬 저장소에 보관되며 제품 서버로 전송되지 않습니다. 제품 서버는 계정 이메일, 로그인 세션, 구독 권한, Paddle 결제 매핑만 저장합니다. 분석, 광고, 원격 로그, 비밀번호 수집이 없습니다. 사용자가 지정한 이미지 URL은 업로드를 위해 요청될 수 있으며 판매자센터 자체의 처리는 각 마켓 정책을 따릅니다.

각 마켓과 독립적으로 개발된 도구입니다. 로그인·CAPTCHA·본인인증은 사용자가 직접 수행합니다.
